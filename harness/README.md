# Full-Stack Harness

Simulates the entire compile as one process: Great Scale geometry, CONTROL12 v5
admission (five HOLD states), Avrone evolve with residual saturation, TrainLLM
ed25519/blake3 spine, CycleKernel evidence-based trust (replacing dice),
capability-plane executor as single choke point, and the attested-history index.

## Nine paths

- **A_clean** — measured, lined, capable, cool → ADMITTED + EXECUTED
- **B_unlineaged** — no human ancestor → HOLD_UNLINEAGED
- **C_unmeasured** — no residual → HOLD_UNMEASURED
- **D_hot** — S above threshold → HOLD_HOT
- **E_uncapable** — no signed capability → HOLD_UNCAPABLE
- **F_poisoned** — broken provenance chain → HOLD_POISONED
- **H_expired** — scope past expiry → REJECTED_EXPIRED
- **I_bad_sig** — signature mismatch → REJECTED_SIG

## Success criteria

Every path terminates in a named state. No silent pass. No number without a story.
The audit log is never softer than the state it certifies.

## Run

```bash
python harness/full_stack_sim.py
```
